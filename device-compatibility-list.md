# Device compatibility list

If you have semistatic bearings working in a device or want to test a device and need assistance, please [open an issue](https://github.com/scatterthought/semistatic-bearing/issues) so that it can be added to the compatibility list.

## Confirmed working

| Device | Semistatic bearing | Comments |
| ---- | ---- | ---- |
| [efog.tech Endgame](https://efog.tech/products/endgame-trackball-complete-diy-kit) | [BR8](https://github.com/scatterthought/semistatic-bearing/blob/main/bosch-rexroth/README.md) | 
| [Ploopy Adept](https://ploopy.co/adept-trackball/) - [Anyball mod](https://github.com/adept-anyball/) | [BR8](https://github.com/scatterthought/semistatic-bearing/blob/main/bosch-rexroth/README.md) | May require 1mm spacer rings |
| Ploopy Classic 1 - [BTU Mod](https://github.com/ploopyco/classic-trackball/tree/master/hardware/Mechanicals-BTU-Mod) | [BR8](https://github.com/scatterthought/semistatic-bearing/blob/main/bosch-rexroth/README.md) | 4mm spacers on two of the three BTU sockets |
| [Ploopy Classic 2](https://ploopy.co/classic-2-trackball/) - [BTU Mod](https://codeberg.org/killmaster/Ploopy-Classic-2-BTU) | [BR8](https://github.com/scatterthought/semistatic-bearing/blob/main/bosch-rexroth/README.md) | 8mm spacer on one of the BTU sockets |

## Testing in progress

### Ploopy Nano 1
- Development of a bearing-replacement mod based on [Ploopy Nano with Button](https://www.reddit.com/r/ploopy/comments/1m1xlq1/ploopy_nano_with_button/).
- Project uses the [Semistatic-VC75-open.stl](https://github.com/scatterthought/semistatic-bearing/blob/main/veichu/semistatic-vc75-open.stl) bearing.
- Mod will be published when testing is completed.

### Ploopy Thumb
- A bearing has been developed to match the dimensions of the NL-8H POM BTU used in the Ploopy Thumb Mod.
- To be added to repository when testing has been completed.

## Needs testing

### Kensington Expert
- A flushmount bearing has been developed for the Expert, but has not been tested with a functional device.
- The bearing is designed to fit into a hole drilled with a 12.7mm (1/2") bit.
- It may be possible to use this bearing on a wide range of trackballs.

## Testing wishlist
