# Device compatibility list

If you have semistatic bearings working in a device or want to test and need assistance, please [open an issue](https://github.com/scatterthought/semistatic-bearing/issues).

## Testing in progress

### Ploopy Nano 1
- Mod based on [Ploopy Nano with Button](https://www.reddit.com/r/ploopy/comments/1m1xlq1/ploopy_nano_with_button/) using [Semistatic-VC75-open.stl](https://github.com/scatterthought/semistatic-bearing/blob/main/veichu/semistatic-vc75-open.stl) bearing.

### Ploopy Thumb
- A bearing has been developed to match the dimensions of the NL-8H POM BTU used in the Ploopy Thumb Mod.
- To be added to repository when testing has been completed.

## Needs testing

### Kensington Expert
- A flushmount bearing has been developed for the Expert, but has not been tested with a functional device.
- The bearing is designed to fit into a hole drilled with a 12.7mm (1/2") bit.
- It may be possible to use this bearing on a wide range of trackballs.
